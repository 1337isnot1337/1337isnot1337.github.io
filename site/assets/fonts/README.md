# Self-hosted fonts

Each family has its SIL Open Font License beside the font files.

DM Sans 4.004 uses its real 100–1000 weight axis. The two unmodified WOFF2 subsets came from the official Google Fonts stylesheet; Latin Extended supplies characters such as ő rather than falling back to another family.

- [Latin WOFF2](https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2) → `body.woff2`
- [Latin Extended WOFF2](https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu6-K6h9Q.woff2) → `body-ext.woff2`
- [Upstream license](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt)

The stylesheet declares each subset’s supported Unicode range. Font requests stay on this site; visitors do not contact Google Fonts.
