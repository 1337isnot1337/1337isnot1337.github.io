About

Cinna Davis.

I build software, work on mathematical proofs, and use code for research in physics and robotics. I'm a senior at the Illinois Mathematics and Science Academy.

Neuralink

In summer 2027, I’ll be joining Neuralink as a Software Engineer Intern on the implant team in Austin, Texas.

Software and mathematics

I build DOPPLERGEIST, which searches recordings for aircraft Doppler patterns and compares them with historical flight tracks.

My mathematics projects include deterministic integer factoring and Conway's 99-graph. The conjecture catalogue distinguishes formalized results from partial or unverified work; its notes are unrefereed.

Hardware and physics

I lead programming for Titan Robotics, FIRST Team 2022, teaching newer programmers, reviewing code and developing robot software.

With Dr. Peter Dong's group in IMSA–CMS through Fermilab, I work on software for a search for a doubly charged Higgs boson. An IMSA research abstract documents related work with Nathan Catlett. My Hack CPU project explores branch prediction in a pipelined processor.
